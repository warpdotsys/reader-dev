# Font Files

The following TTF font files are used by the reader for custom font rendering.
They are stored in `src/main/resources/simple-web/assets/font/`:

- `Myuppy.ttf` - Myuppy handwriting font
- `书体坊郭小语钢笔楷体.ttf` - Pen calligraphy style
- `字体管家楷体.ttf` - Kai style managed font
- `方正宋刻本秀楷简.ttf` - Fang Zheng Song Ke Ben style
- `杨任东竹石体.ttf` - Yang Ren Dong bamboo/stone style

These are referenced via @font-face declarations in `css/read.css`.
