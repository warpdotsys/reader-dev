# 本机维护工具状态

该目录同时保留 v6.1.0 的专用维护脚本与尚未集成的新候选工具。二者不能混用，也不能通过更改硬编码目录绕过身份检查。

| 工具 | 当前用途 | 限制 |
| --- | --- | --- |
| ReaderLocal.ps1 与既有 prepare/service 等脚本 | 既有 v6.1.0 本机完整镜像 | 绑定该版本的目录、端口与镜像，不用于 v6.1.1 候选 |
| candidate-profile.py | 校验新候选版本、软件哈希、路径与资源预算 | 仅校验，不挂载、格式化或启动 |
| full-backup.py | 生成数据下的完整备份事务和恢复模型 | 正式执行主动拒绝，等待共享生命周期锁和启动事务守卫接通 |
| ReaderCandidateAutostart.ps1 | 可选的登录后自启设计与生成测试 | 默认 Plan；没有正式启用或登录后验收，不承诺自动启动成功 |

不要把这些实验性工具用于唯一一份数据。完整备份需包括全局账号、用户存储、许可证数据库和密钥；恢复后的登录、授权、阅读及权限仍需整体验证。

测试不得注册真实系统任务、重启主机或停止全局 WSL。自启测试使用生成调度器适配器；备份中断测试使用生成目录。任何实际启用都必须另行明确授权。
