## 可读源码修复

- 新缓存键 `reader_shelf_offline_v2:` 使用现有章节缓存的部署 origin/base、账号和实际配置空间规则；凭据只用于判定是否登录，不放入缓存名称。同账号换 token 可使用其最近完整快照，不同账号、子目录、管理员 default 配置空间不能互读。
- 旧共享键 `reader_shelf_offline` 无法确定归属，不读取、不自动迁移、不删除。升级后的首次断网若无本账号新缓存，就不会显示旧共享记录；联网加载成功后建立新快照。
- 本地封套校验版本、scope、书籍/分组字段和时间戳；损坏/缺字段的数据不会通过补造默认值冒充有效快照，配额/存储异常不会被报告为保存成功。
- 只在书架与分组均成功时保存完整快照；分组失败仍可展示本次真实在线书架，但不以伪空分组覆盖上一完整快照。
- 离线降级只接受明确网络错误、超时和 HTTP 502/503/504。认证、业务拒绝、取消、旧会话、配置错误及其他 HTTP 状态不冒充离线成功；认证错误仍由原会话守卫处理。
- 组件捕获会话/缓存空间、刷新代数和卸载状态。身份变化同步隐藏旧书架，最终身份更新后再加载；旧刷新或已卸载组件不更新画面、缓存或新请求的加载状态。

不更改 Java/Kotlin 后端、服务端用户命名空间、文件格式、生产用户数上限或原始 JAR；没有字节码补丁。
