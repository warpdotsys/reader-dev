# Reader Pro v4.0.7-restored.8

本版继续维护 Java/Kotlin 恢复工程，不包含 Go/Rust 全量重写。构建、部署和 GitHub Release 均通过 GitHub 托管 runner 完成。

## 本次修复

- 修复搜索结果 JSON 额外暴露内部 `_userNameSpace` 字段；补充序列化单测。
- 修正多书源搜索和换源 SSE 在扫描完最后一个书源时仍返回 `isEnd=false` 的零基索引错误；补充索引边界单测。
- 增加固定本机书源和线上现有真实书源的可重复黑盒差分脚本。原始 JAR 始终保留作对照，不修改生产用户数据。

## 发布前验证

- JDK 11 下 `clean test bootJar` 成功。
- 原始 JAR 与恢复版：认证生命周期 11 项完全一致；文件/本地阅读 25 项中 23 项一致、2 项已记录改进；固定远程书源 8 项中 5 项一致、3 项已记录差异。
- 线上现有真实书源：两版搜索 100 条、目录 1914 章、首章正文 2852 字符，搜索书目、详情关键字段、全部目录项和正文摘要一致。
- 两种 SSE 均收到真正的 `event: end`；事件数据一致，终帧 `isEnd` 仅恢复版按正确边界返回 `true`。这是有意修复，不伪称与原 JAR 字节完全一致。
- 当前已部署服务的匿名、只读搜索和详情可访问；搜索仍有本版将移除的内部字段。发布后需再次验证线上响应。

## 已知问题与验证边界

- 线上登录后的目录、正文、书架及缓存链路尚未在本版发布前执行生产端到端验证。现有 accessToken 自动登录会改写 `users.json` 的最后登录时间，因此未把它包装成纯只读探针。
- 部分已保存第三方书源本身失效或受站点规则变化影响：实测有两版共同的目录为空、脚本异常、空搜索结果和重定向循环。这些不是本版已解决的问题。
- EPUB/PDF/CBZ、大文件、WebDAV、完整 SSE 多书源并发和所有第三方书源仍未系统性覆盖。
- 原始 JAR 在书架中文字符上存在乱码，恢复版保留编码修复；正文末尾换行等已记录差异仍需客户端兼容观察。
- 许可证中心为旧中心失效后的兼容重建，不能保证覆盖未观察到的旧协议行为。前端继续使用 JAR 内旧版界面，尚未接入 master 的 Vue 3 设计。

## 部署与回滚

部署作业会校验制品 SHA-256，保留前一版 JAR、镜像和 Nginx 配置；健康检查、UTF-8 静态资源校验或公网烟雾测试失败时自动回滚。发布不迁移或覆盖 `storage/data`。生产域名：`https://read.medwarp.cn`。
