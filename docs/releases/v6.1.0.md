# Reader Pro v6.1.0 — Java/Kotlin 恢复主线

本版本恢复长期维护 Java/Kotlin 混合工程，不继续全量 Go/Rust 重写。默认分支为 legacy；业务和原版存储兼容优先，旧工程及原始 JAR 保留作对照。

## 主要变更

- 完整 Reader 镜像内置固定版本 Camoufox、Python、JRE 与依赖；运行不需要宿主 Chrome 或独立 WebView 容器。历史远程引擎保留为显式回退。
- 镜像默认 Vue 3，沿用 Rust 分支的设计语言，保留 Java/Kotlin 登录、用户空间、书架、书源与阅读接口。原 Vue 2 和普通 JAR 的兼容入口保留。
- 修复 EPUB 完整页面退出时的任务清理，分离下载、解压与结果传递诊断；资源按有确认的批次传递，使用有界共享缓冲视图减少传递对象。不丢弃资源、不截断正文。
- 修复合法 DEFLATE 在输出块边界被误判为截断的问题；截断、尾随垃圾、长度谎报及膨胀攻击仍拒绝。
- 保持下载 60 秒、创建 Worker 起共 15 秒及测试观察 30 秒；没有放宽原资源预算或更改正式 JVM 参数来取得通过。
- 统一版本 6.1.0，JAR MANIFEST 写入确定性版本；保留 Gradle Wrapper、可读源码、锁定依赖和双 clean 字节一致门禁。
- 正式制品由 GitHub 托管 runner 构建、原生双架构测试和新 runner 重载验证；发布器导入同一已验证归档，不重新构建替代。

## 已知问题

1. 起点真实登录态的搜索和免费首章未验证。用户已停止个人 Chrome 路径，不再连接、提取其会话或要求配合；不复用已清理 Cookie，不购买章节或自动验证码。匿名公开页及生成账号测试不算真实站点认证。
2. 大书兼容仍是有限样本。当前候选的生成 96 场景及授权书 8/8 已通过，但不证明全部 EPUB、所有原版 storage 或冷态 / 长期生产稳定。此前 80 候选真实书 6/8 的 15 秒传递超时及更早失败保留于对应证据，不被改记成功；也不直接当作当前候选已复现相同故障。
3. 半小时长测静止内存增长分别为 63,176,704 / 45,727,744 B。未触及硬内存 / OOM / PID 限额，且故障后自有浏览器子进程清零；仍不能宣称长期无泄漏或证明生产容量。这是后端 / 包内浏览器生成请求长测，不是前端 EPUB 连续阅读。
4. 当前许可证服务源码的试用邮件接口明确返回“未配置”错误；未完成线上发送或许可证激活验收，不宣称 SMTP 可用。公钥匹配、健康接口和首页 HTTP 200 仅属前置检查。本机访问生产域名曾超时，服务器侧严格 TLS 访问正常，原因尚未证明。
5. 保留有意兼容差异：原 JAR 的 Book 请求共用 default 空间，恢复版隔离用户；历史 Cookie 不重放，当前重放后可清除；历史 UTF-8 POST 损坏、忽略 TLS 错误的行为不继续复制。时钟字段在各自真实请求窗口内验证，不要求字面相等，不宣传完全兼容。
6. 所有第三方书源、边缘业务和前端页面尚未穷尽；备用 cli.gradle 不是正式构建。缓存导出实测超过 60 秒，不宣称严格总上限或因果加速。测试的 2 CPU / 硬 2 GiB 不自动等于生产 Compose 已配置同样限额。

## 构建与发布

本机保留输入的构建入口（PowerShell 7，恢复工程目录）：

~~~powershell
pwsh -NoProfile -File .\scripts\build.ps1
~~~

普通 JAR 不自带完整浏览器运行时。正式标签必须来自 legacy、为严格稳定 SemVer、高于当时最新正式版并与所有版本清单一致。GitHub Actions 验证完整 Vue 3、准确双架构整镜像及发布器，再发布 GitHub Release、GHCR 与 Docker Hub；不以手工构建代替。
