# Reader Pro v4.0.7-restored.1

这是从 `reader-pro-3.2.14.jar`、可验证的历史源码和人工整理代码恢复出的首个可重复构建版本。该版本继续维护 Java/Kotlin 混合工程，不是 Go/Rust 重写版，也不宣称与原始闭源构建逐字节一致。

## 本次发布

- 恢复 Gradle Wrapper、JDK 11、Kotlin、Spring Boot 与 Vert.x 构建链。
- 保留原版前端与现有 `storage/data` 数据格式。
- 将许可证中心切换到自托管的 `license.medwarp.cn`。
- 修复 Windows 构建时 Gradle 使用系统默认编码处理 UTF-8 Vue 资源，导致界面中文乱码的问题。
- 增加静态资源严格 UTF-8 回归测试和 PWA 缓存代际更新。
- 增加 GitHub Actions 的测试、制品校验、生产部署、失败回滚及 GitHub Release 流程。

## 已验证

- Gradle 全量测试和 Boot JAR 构建成功。
- 核心前端 JS 可按严格 UTF-8 解码。
- 首页与 `/reader3/getSystemInfo` 可访问。
- 一个导入账户的登录、accessToken、用户信息、169 项书架和 429 项书源已验证。
- 55,692 个数据文件、780,079,185 字节已导入并复核。
- 生产容器健康检查、公网 HTTPS 和证书续期验证通过。

## 已知问题与验证边界

- 这是恢复版本：部分实现来自与 JAR 接近但不保证同版的源码，仍需继续做黑盒差分验证。
- WebDAV、SSE 长连接、大文件下载、第三方书源和全部写接口尚未完成系统性回归。
- 许可证中心是为失效旧中心重新实现的兼容服务，不保证覆盖旧中心所有未观察到的协议行为。
- 前端暂时保留 JAR 内旧版界面；尚未接入 Rust/master 分支的 Vue 3 设计。
- 当前只对一个有效账户完成端到端登录与数据读取验证，其他账户及极端数据尚待覆盖。
- 服务器既有 Nginx 配置存在与本项目无关的 `cdn.medwarp.cn` 重复 `server_name` 警告；不影响本域名启动，但应另行清理。

## 升级提示

本次修复会切换 PWA 缓存代际。已打开页面通常刷新一次即可获取新资源；如果浏览器仍显示旧乱码，请执行一次强制刷新。

## 回滚

生产部署在替换前保存上一版 JAR、Docker 镜像和 Nginx 配置。健康检查、UTF-8 校验或公网烟雾测试失败时，流水线会自动恢复上一版本。
