# Vue 3 正文编辑与本机缓存隔离

更新日期：2026-10-05。源码候选，不是正式发版或生产验收。

## 实际复现

全部使用独立的 `127.0.0.1:18945` Reader、`18946` 生成书源、全新 Chrome 浏览器上下文及两个随机生成账号。没有读取真实正文、复用用户浏览器登录态、使用起点 Cookie 或修改生产数据。用户 Reader `18931/PID 61244` 不在测试范围。

1. **已从恢复源码核对，并由界面复现失败**：Vue 3 编辑正文发送 `bookUrl/chapterUrl/title/content`，Java/Kotlin `saveBookContent` 实际接收 `url/index/content`。首次旧候选测试停在编辑保存后的正文断言，尚未到达跨账号检查，不能将其当作缓存串号证据。
2. **已实际复现跨账号缓存正文**：仅修复编辑请求并重建后，甲账号编辑/刷新成功，响应为 HTTP 200、`isSuccess=true`，请求确实包含 `url` 与完整目录 `index=0`。退出并登录乙账号，乙账号直接请求服务器得到生成书源原正文，但阅读页显示甲账号的独有生成正文。失败 XML 和截图保留，目视确认不是错误提示或空页面。
3. **已从源码核对原因**：IndexedDB `reader-local-cache` 的主键仅含书籍/章节 URL，不含账号或配置命名空间。同一浏览器同源下，两个账号访问相同 URL 命中同一条记录。

## 源码修复

- 编辑正文复用类型明确的 `saveBookContent(url, index, content)`，使用完整目录下标，而非过滤卷标题后的本机序号。
- 新缓存数据库按部署同源/前端根路径、登录账号、实际配置命名空间隔离，前缀为 `reader-local-cache-v2:`。管理员普通与 `default` 配置层分开；不同管理员仍分开。缓存作用域和库名不包含 accessToken；重新登录同一账号不会生成另一份缓存。
- 未登录时关闭所有本机章节缓存读写、批量写入、列举和清除。IndexedDB 不可用时继续真实服务器请求，不伪造正文或写入成功。
- 正文读取、编辑、目录缓存标记、批量缓存与单书清除捕获作用域和短期会话，在等待结束后校验身份。正文读取另有请求序号，离开页面后失效；批量任务使用序号，旧取消任务不会因新任务启动而复活。单章写入失败不累计成功数。
- 普通阅读进度也使用新作用域键；失效身份不再保存旧页面进度。设备级字体/主题、统计、书籍配置等仍有独立范围，本修复不宣称所有客户端数据都已完成账号隔离。

## 数据与回滚注意事项

旧 `reader-local-cache` 无法确认归属，**不读取、不自动迁移、不删除**；旧共享阅读进度键也保持原样但不自动恢复。首次升级需要重新拉取所需章节，可能增加请求量；无网络且只有旧共享缓存时，不能把未知归属正文默认分配给当前用户。服务器 storage、书架、自定义正文格式与 Java/Kotlin 业务实现未改变。

回滚应使用之前完整候选或发布产物；新缓存库不会被旧实现读取，新旧记录均保留。旧 UI 本身存在共享缓存缺陷，回滚不是账号隔离安全修复；共享设备应避免使用旧 UI 的跨账号缓存。不建议清空整个站点存储，那里可能含用户数据与登录态。
