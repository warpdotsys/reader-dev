# 线上原版 Chrome 登录核验

日期：2026-09-28。目标为 `https://read.medwarp.cn/#/` 当前部署页面，不是本分支的恢复构建。页面显示版本 `v3.2.14-05250935`。

在用户明确授权下，于 Chrome 新标签页完成真实登录表单提交。提交后登录弹窗关闭，页面显示“后端已连接”“注销”，并加载出非空书架和书源分组；因此这一次 **Chrome 中的线上原版网页登录及基本业务数据加载成功**。测试未执行删除、导入、配置同步或管理操作，也未在报告中记录凭据、令牌、书名及页面截图。登录前取消了“记住登录信息”选项；这不等于保证浏览器不会留下正常会话状态。

排查中发现：浏览器只读 DOM 检查对密码框 `value` 返回长度 0，但可见截图中密码掩码非空，实际提交也成功。因此不能单凭该只读值断定密码没有输入；后续自动化应结合可见状态与提交后的业务状态判断。

边界：这不是 Edge 的复现结果，不证明用户之前遇到的问题不存在；也不证明候选恢复版的 Vue 3 登录已通过线上验收。候选分支仍未部署到生产，不能将这次线上原版成功记作恢复版通过。

2026-09-29 在 Chrome 中再次核验同一线上原版：初次打开时前端短暂显示“点击设置后端接口前缀”与空书架，读取到已配置的 `//read.medwarp.cn/reader3` 后页面自行连接，书架显示 169 本。为验证新登录而非沿用会话，退出旧会话、取消“记住登录信息”、提交用户授权的原账号；登录弹窗关闭后再次出现“后端已连接”“注销”和 169 本书。过程中未修改书籍、书源或服务器配置。初始空书架属于加载中的瞬时状态，不能单凭该截图判定登录失败；同样，这次成功不涵盖其他浏览器、其他账号或候选 Vue 3 的生产部署。
