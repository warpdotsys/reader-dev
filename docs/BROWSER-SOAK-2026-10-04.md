本轮本机 Python 全量 88 项、0 失败/错误、1 项平台门控跳过；新增连续运行夹具 9 项和资源校验 9 项均实际执行通过。47 项发布结构/制品/manifest 单元测试、工作流 actionlint 与脚本语法检查通过。这些是本机单元/结构验证，不证明镜像连续运行、异常退出恢复或生产稳定。

## 夹具与门禁

- 全新生成存储，独立回环端口 18892；拒绝复用已有容器/存储/报告。工作负载代码只接受此端口，拒绝生产域名、18931、URL 凭据及 token 查询参数。
- Docker `--network none`；脚本核实命名空间只有 loopback。Reader、夹具、验证程序都在**同一** 2 CPU / 2 GiB / 256 PID、无 swap 的完整 Reader 容器预算内。不依赖宿主 Chrome、额外 WebView 服务或外网。
- 四个生成用户复用各自独立 Cookie Jar；循环交替 GET/POST，实际目标核对请求头/请求体、用户独有的生成书名、Cookie 首次为空与后续回放。记录计数，不保存账号、token 或 Cookie 值。
- 首次请求、预热后与每轮完成时采样 cgroup；每次完成后最多等 10 秒，确认 Camoufox 及辅助程序、Playwright driver、Python worker 的进程消失。进程检查不读取环境变量，不输出完整命令行。
- 主导航故意卡住、书源脚本死循环、正在导航的测试 Python worker 意外退出三种故障，分别要求 HTTP 响应中的 ReturnData 业务失败及正确错误类型，而非以 HTTP 200 算成功。之后必须实际完成健康请求、重新检查进程回收。异常退出只向此无外网容器内 UID 10001、已观测到的唯一 `/tmp/reader-camoufox-worker-*.py` worker 发信号，不操作 Java、PID 1、宿主进程或生产服务。
- 连续阶段默认 1,800 秒，至少 20 轮四用户突发；达到时间且轮数门槛才成功。另允许明确选择 600/3,600 秒。报告包括实际时长、GET/POST 计数、异常恢复、内存/任务峰值、逐轮静默采样及全部原始限额计数；触限、OOM、遗留进程、Cookie 越用户或请求形态错误均失败。
- 小型报告失败时也上传；容器按实际创建 ID 清理，生成存储仅在临时 runner 留到作业结束，不覆盖用户数据。
