## 本次源码变更

新增 `releaseEpubDoc` 作为终态释放：回收URL后清空持有的完整资源Map、manifest、spine和路径基准。撤销某URL失败时仍尝试其余URL、清掉字节引用并保留首个异常；重复最终释放安全，不修改源ZIP或存储文件，也不影响另一个新文档。

`ReaderView`仅在已取消 / 旧身份加载结果和组件卸载时调用最终释放；卸载先取消加载、清掉文档持有引用及目录，再释放已持有文档。活动阅读文档及普通 / HTML / 原版模式切换没有改成终态释放，旧 `destroyEpubDoc` 的CSS重建测试仍通过。没有增加pagehide / BFCache处理，不把组件卸载钩子冒称所有浏览器硬刷新的完整生命周期。

这修补了“仍被异步闭包持有的已作废文档继续引用整本解压字节”的显式所有权缺口，**尚未证明它是Y硬刷新失败的根因**。释放引用不等于立刻回收浏览器RSS；不承诺内存峰下降或15秒刷新超时已消失。

Java/Kotlin后端、用户命名空间、认证、存储格式、ZIP算法、Worker阶段协议、资源/进程预算及下载60秒 / Worker15秒均未改。
