# EPUB 原生解压候选：未接受，已撤回产品改动

## 已验证的局部结果

Firefox 的专用 Worker 对生成 64 KiB 数据执行 `deflate-raw`、`deflate`、`gzip`，三种格式均完整逐字节恢复，并拒绝截断及尾随垃圾。这是格式能力检查，不是 ZIP 或 Reader 验收。页面侧同一探针发生 `autoAllocateChunkSize` 权限错误，原因未确认，总体探针仍失败；没有关闭安全设置来消除它。格式和错误预期参考 [WHATWG Compression](https://compression.spec.whatwg.org/#supported-formats)。

局部源码候选保留中央目录预算、规范化路径、本地/中央一致性、实际输出计数，以及原 15 秒 Worker 总期限。只在构造接口不受支持时回退到旧解码路径；已经开始的原生解码失败不会改用旧解码来掩盖错误。压缩输入先由既有 ZIP 流解析器分帧，再逐个条目实际解码；不是空实现，也不并发打开整本书全部解压流。

本机构建成功，360 项前端测试零失败，类型检查与 Vite 成功。新增七项覆盖逐字节恢复、数据描述符、32 MiB 低报 16 字节、高报/缺失/冲突、各预算、路径和失败不回退。获准单书的全部 1,673 资源、49,382,784 展开字节与旧算法逐字节一致。Node 单轮旧/原生算法耗时 2,143/1,161 ms，不代表 Firefox 速度或 Reader 稳定性。

## 完整 Reader 的反例

候选 JAR 完整 SHA-256：`b004d994d19a657fb52350786fb472dd610f29e0123c5aad09912c2fd54bb8be`。EPUB Worker SHA-256：`7f63fd7be42d8b0ecab3eec67db63c62aa5482d42bad7db38d521edeedf06d0d`。实际镜像运行时仍是既有缓存版本，不是最新完整镜像本机验收；此 JAR 未经新一轮托管双 clean 构建。

两轮保留原始 JAR 生成账号、认证/注销/重登/用户隔离、真实导入、完整八场景和原 2 CPU/2 GiB/256 PID/零交换门槛。

- AL：完成六项；原版排版硬刷新出现 iframe，没有 Worker 超时，但原严格正文 SHA 比较失败。105.642 秒，内存峰值 1,622,016,000 字节。未取得正文变化原因，不能宣称内容损坏或仅是渲染时机。
- AM：只新增私有分类比较和固定数值元数据，仍保留原严格断言；首次原版排版在 Worker 解压阶段超时，仅完成四项，新增刷新比较未到达。137.960 秒，内存峰值 1,624,387,584 字节。不能把未执行的比较当作原因证据。

因此局部字节一致、Node 加速和格式可用均不能支撑稳定修复。没有发版、部署、合并或上传镜像。

## 撤回和清理

已撤回本轮对正式 `epubArchive.ts`、`epubArchive.worker.ts` 的原生改动，并移出本轮七项原生测试。源文件恢复到既有实现，保留此前新增的 32 MiB 伪造头安全回归。候选源码、测试快照和 JAR 在独立 `build/native-deflate-candidate-20261013-a` 保留，失败报告没有删除；撤回后重新检查全量测试和普通构建产物，避免源码与默认 JAR 混用。

撤回后 353 项全量前端零失败，Vite 成功；普通 Gradle 构建成功，默认 JAR 恢复为既有 A01 的完整字节：`a01ac3afba310393b997fe7d543d7664717148702591182e4f4b27a0e723356b`，285,679,758 字节。EPUB Worker 恢复 `59ebfb6a…64ed9f1`，解码源码恢复 `a45e8b36…4a9c1d`。候选 B004 JAR 另存保留，没有覆盖对照来源。

两轮服务已停止、PID 为零、独立 runtime 清单为空；各三份输入经绝对路径、只读权限、所有者、单链接、大小及哈希验证后逐一清理。来源、原始 JAR、既有工程和 58 用户报告保留。公开证据仅有数值、阶段和比较布尔值，不含正文、私有路径/名称、账号、令牌或正文哈希。

证据：[Worker 格式能力及页面反例](evidence/native-deflate-worker-capability-2026-10-13.json)、[首轮完整 Reader 失败](evidence/native-deflate-reader-trial-2026-10-13.json)、[次轮失败、撤回及默认产物复原](evidence/native-deflate-trial-rejected-2026-10-13.json)。

## 尚未解决

大型 EPUB 原版排版仍有解压超时、硬刷新严格正文比较失败和 iframe 可见性不稳定。是否存在就绪采样或章节交接问题尚未验证。下一项应以小型生成的多章书明确区分“页面已有文字”和“目标章节已就绪”，取得直接证据后再调整验收或产品；不重复仅基于解压速度推测根因。
