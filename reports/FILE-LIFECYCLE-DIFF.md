## 已修复的差异

首轮差分为 10/12：在 Windows 上，原始 JAR 的文件列表路径使用系统分隔符（如 `\notes\差分.txt`），恢复版统一成了 `/notes/差分.txt`。依据黑盒结果，将 `FileController.list` 的路径拼接改回 `File.separator + relativeTo(baseDir).path`，重建后 12/12 一致。在 Linux 上系统分隔符仍为 `/`，因此这项修复不改变线上 Linux 路径形式。

这里只修改了已被黑盒差分证实有偏差的 `list` 响应。`upload`、`parse` 还未进行同等比较，不从相似源码推断它们必须按同样方式修改。
